# Third-party libraries

Reader Studio uses:

- PDF.js 3.11.174 — Mozilla — Apache-2.0 — loaded at runtime from cdnjs.
- epub.js 0.3.93 — FuturePress — BSD-2-Clause — loaded at runtime from jsDelivr.
- JSZip 3.10.1 — MIT or GPL-3.0-or-later — bundled in `vendor/jszip.min.js`.
- Supabase JavaScript client 2.x — Supabase — MIT — loaded at runtime from jsDelivr only when cloud sync is configured.

Quick translation uses the MyMemory public translation API when the user explicitly clicks Translate.
